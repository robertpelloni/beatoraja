Multiplayer Battles

Arena Mode allows you to compete with other players in real-time over a network connection.

Starting Arena Mode

  1. Launch beatoraja.
  2. In the Music Select screen, press F5 to open the Mod Menu.
  3. Select the Arena tab.

Connecting

  • Host Game: Start a server on your machine. Others can join using your IP address.
  • Join Game: Enter the IP address and Port of the host to connect.
  • Player Name: Set your display name in the Launcher configuration (Arena Tab).

Gameplay Rules

Once connected, players enter a shared lobby.

Synchronization

  • Song Selection: When the host selects a song, all connected clients will automatically select the same song if they have it.
  • Ready Check: All players must press START to mark themselves as Ready.
  • Game Start: Once everyone is ready, the host can start the match.

Chat

Communicate with other players in the lobby using the built-in chat feature.

  • Open the Arena window (F5) to see the chat log.
  • Type your message in the input field and press Enter to send.

Score Tracking

During gameplay, scores are synced in real-time. You can see your opponents' current score and rank on the side of the screen (if supported by your skin).

Results

After the song finishes, a ranking screen displays the final scores and winner.

Troubleshooting

  • "Song Not Found": Ensure all players have the exact same BMS file (same hash). Using a different version of the chart will prevent play.
  • Connection Failed: Check your firewall settings. The host must allow incoming connections on the specified port (default: 12345).
  • Lag: Network latency can affect score updates but does not impact your local gameplay timing.
