Key Configuration

In the Input tab, you can assign keys for each play mode.

Play Modes

  • 5KEYS / 7KEYS: Standard single-player modes.
  • 10KEYS / 14KEYS: Double-play modes (two controllers/sides).
  • 9KEYS: Pop'n Music style mode.
  • 24KEYS: Keyboard mania style.

Click on a keybinding and press the desired key on your keyboard or controller to reassign it.

Controller Setup

beatoraja supports USB controllers, MIDI devices, and gamepads.

Analog Scratch Settings

  • Enable Analog Scratch: Check this if your controller supports analog turntable input (e.g., dedicated IIDX controllers).
  • Sensitivity: Adjust how much rotation is needed to register a scratch.
  • Deadzone: Ignore small movements to prevent accidental scratches.

Input Mode

  • DirectInput: Standard Windows input API. Compatible with most older controllers.
  • XInput: Xbox controller standard. Better for modern gamepads.
  • Raw Input: Lower latency, direct hardware access (Recommended for keyboards).

Advanced Options

  • Prevent Double Inputs: Ignores rapid successive inputs on the same key (debouncing).
  • Use Alt Key for Functions: Use Alt key combinations for system functions.
  • Mouse Input: Enable mouse clicks/movements as game inputs (useful for scratch).
