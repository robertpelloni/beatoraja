Course Editor

← Back to Index

Overview

The Course Editor allows you to create custom courses (Nonstop or Dan/Class courses) by selecting songs from your database. Courses are saved as standard BMS course files (.crs) which can be played in Course Mode.

Using the Editor

1. Searching for Songs

In the "Course Editor" tab of the Launcher:

  • Type a song title or artist name into the Search Field.
  • The table below will populate with matching songs found in your database.

2. Building the Course

Once you find a song you want to add:

  1. Select the song in the search results table.
  2. Click the Add Song button (or double-click, if supported).
  3. The song will appear in the "Course Songs" list on the right.
  4. Repeat this process for all stages (typically 4 songs for a standard course).

3. Editing the List

  • To remove a song, select it in the "Course Songs" list and click Remove Song.
  • Use the Up / Down buttons (if available) to reorder stages.

4. Saving the Course

  • Enter a Course Title in the provided text field (e.g., "My Favorite Trance Mix").
  • Click Save Course.
  • A file dialog will open. Choose a location to save your .crs file.
  • We recommend saving it in a dedicated folder within your BMS root directory (e.g., bms/courses/my_course.crs) so beatoraja can easily find it on the next reload.

File Format

The editor saves files in the standard BMS Course format. Example:

#TITLE My Course
#ARTIST User
#DIFFICULTY 5
#STAGEfile C:\BMS\Song1\file.bms
#STAGEfile C:\BMS\Song2\file.bms

This ensures compatibility with other BMS players that support absolute path referencing.
