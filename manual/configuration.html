Initial Setup

Before launching the game, use the Launcher to configure essential settings like audio, video, and song folders.

Resource Tab

BMS Path

Add the root directory where your BMS folders are located. The game will scan subdirectories for songs.

Table URL

Add URLs to Difficulty Tables (JSON/HTML). These tables organize songs into difficulty tiers (e.g., Insane BMS, Stella, Satellite).

  • Update BMS Database: Force a full rescan of all song folders. Recommended when adding new songs.

Video Tab

Display Mode

  • Windowed: Runs the game in a window.
  • Fullscreen: Exclusive fullscreen mode for best performance.
  • Borderless: Maximized window without borders (easier for alt-tabbing).

Resolution

Select your desired resolution. Higher resolutions require more GPU power.

VSync

Synchronize frame rate with monitor refresh rate to prevent tearing. Disable for lower input latency.

Max FPS

Limit the frame rate to save power or match your monitor (e.g., 240Hz, 144Hz).

Audio Tab

Audio Driver

  • PortAudio: Low-latency audio driver (Recommended).
  • OpenAL: Standard cross-platform audio.

Buffer Size

Lower values reduce audio latency but may cause crackling on slower systems.

Sample Rate

Typically 44100Hz or 48000Hz. Match your system settings.

Other Settings

Detailed Options

  • Discord RPC: Show your current song and status on Discord.
  • Screenshot to Clipboard: Automatically copy screenshots to clipboard when taken (F6).
  • IPFS: Enable decentralized song downloading via IPFS.
