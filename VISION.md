# Project Vision

## The Ultimate BMS Player

**beatoraja** aims to be the definitive, feature-complete, cross-platform rhythm game player for BMS and related formats. It strives for:

1.  **Universal Compatibility:**
    *   Support all BMS variations (BMS, BME, BML, PMS).
    *   Support Osu! beatmaps (`.osu`) with full feature parity (Sliders, Spinners, Storyboards).
    *   Cross-platform support (Windows, Mac, Linux).

2.  **Robust Feature Set:**
    *   **Accurate Engine:** Precise timing, custom judgment windows (Fast/Slow), and highly configurable play options.
    *   **Social Play:** Seamless multiplayer (Arena) with chat, score syncing, and rankings.
    *   **Progression:** Deep single-player content via Course Mode (Dan), Step-Up Mode, and Missions.
    *   **Creation:** Built-in tools for content creation (Course Editor).

3.  **User Experience:**
    *   **Configuration:** A comprehensive Launcher that exposes *every* setting.
    *   **In-Game Control:** Immediate access to settings via Mod Menu (F5).
    *   **Documentation:** High-quality, up-to-date manuals for all features.

4.  **Extensibility:**
    *   **Skinning:** A powerful JSON/Lua skinning engine allowing infinite customization.
    *   **Plugins:** Support for IR (Internet Ranking) and external tools.

## Design Philosophy

*   **"If it exists in the backend, it must exist in the UI."** No hidden config files.
*   **"Documentation is part of the feature."** A feature is not complete until it is documented.
*   **"Autonomy and Speed."** Development should proceed rapidly, fixing issues as they arise, with a focus on momentum.
